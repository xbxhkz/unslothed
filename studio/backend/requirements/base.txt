# Shared torch-bound ML requirements, applied unchanged on fresh install.sh /
# install.ps1 installs and on `unsloth studio update`.
#
# Not unsloth or unsloth-zoo: those are the separately skippable core phase, which
# the shell installers install inline first.
# Not diffusers: its pin must run after every other requirements file so a later
# pass cannot replace it, so it lives in diffusers-pin.txt with its own late step.

# Agent vision tools (detect_shapes, webcam_look). Torch-bound, so they belong
# here rather than in studio.txt: this file is skipped entirely under NO_TORCH,
# where a GGUF-only install has no torch for them to run on anyway. Without
# these declared, both tools died with ModuleNotFoundError on any clean install
# and only worked on dev boxes that happened to carry them from elsewhere.
#
# Pinned to the torchvision that pairs with the pinned torch (2.10.0). A bare
# name here resolves to whatever is newest at install time, which in a Docker
# image rebuilt months later can pull a torchvision incompatible with torch --
# surfacing as a CUDA error rather than a version mismatch.
torchvision==0.25.0
# detect_shapes uses torchvision's Mask R-CNN; webcam_look uses ultralytics YOLO.
ultralytics==8.4.47
